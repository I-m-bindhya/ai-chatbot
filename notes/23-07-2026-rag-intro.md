1. Why can't we simply increase the number of stored messages instead of using retrieval?

Increasing the message window eventually exceeds the model's context budget and increases latency and cost. More importantly, chronological messages are not necessarily the most relevant. Retrieval selects information based on semantic relevance rather than recency, allowing the model to access important historical information efficiently.


2.  Chat Model          | Embedding Model              |
| --------------------- | ---------------------------- |
| Generates text        | Generates vectors            |
| Answers questions     | Represents meaning           |
| Predicts next tokens  | Encodes semantic information |
| Used in conversations | Used in search and retrieval |


3. What is an embedding?

An embedding is a numerical vector representation of text that captures its semantic meaning. Instead of storing only the original words, embedding models map text into a high-dimensional vector space where semantically similar text is located close together. This enables similarity search, semantic retrieval, clustering, and recommendation systems.

4. SQL searches words. Embeddings search meaning.

5. The chat model already understands language. Why not ask it to search? 

Because the jobs are different. The embedding model is optimized for representation, while the chat model is optimized for generation.

6. What is the role of an embedding model in a RAG system?

The embedding model converts both documents and user queries into vector representations. These vectors are compared in a vector database to retrieve semantically relevant documents, which are then included in the LLM's context to generate a more accurate response.

7. In general mathematics, a vector is simply an ordered list of numbers. In AI, we reuse the same mathematical concept.
Instead of representing direction or movement, a vector represents the meaning of data.That list of numbers is called an embedding vector. A vector is a numeric representation of data. In embedding models, it is a numeric representation that captures the semantic meaning of the input. In AI, an embedding vector is a numerical representation of data that captures its semantic meaning, allowing similarity comparisons between different pieces of information.

8. What is a Document?

This is one of the most important concepts in RAG. A document is simply a unit of information that can be embedded and retrieved. It may be a PDF section, a webpage, a database record, a chat message, source code, or any other text. In practice, large documents are split into smaller chunks before embedding to improve retrieval accuracy.

9. Why can't we use a relational database like SQLite for semantic search?

While a relational database can store embedding vectors, it is not optimized for efficient nearest-neighbor similarity search. Vector databases build specialized indexes that allow fast retrieval of semantically similar vectors, making them suitable for large-scale retrieval systems used in RAG applications.

10. What problem does RAG solve? 

RAG enables an LLM to answer questions using external, up-to-date, or domain-specific knowledge without retraining the model. The application retrieves relevant information from a knowledge base, augments the prompt with that information, and then asks the LLM to generate a grounded response.

If we only send the last 10 messages:

Therefore, it cannot answer:

- The model only knows the context provided in the current request

# 6. ContextBuilder Implementation

File:

```
src/context/context_builder.py
```

Implementation:

```python
class ContextBuilder:

    def __init__(self, memory_manager):
        self.memory_manager = memory_manager


    def build_context(
        self,
        conversation_id,
        user_message,
        retrieved_documents=None,
        tool_messages=None
    ):

        messages = list(
            self.memory_manager.build_context(
                conversation_id
            )
        )


        messages.append(
            {
                "role": "user",
                "content": user_message
            }
        )


        if retrieved_documents:
            messages.extend(
                retrieved_documents
            )


        if tool_messages:
            messages.extend(
                tool_messages
            )


        return messages
```
